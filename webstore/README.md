# Paquete FocusGuard — Chrome Web Store

Todos los assets listos para subir tu extensión al Chrome Web Store.

## Contenido

| Archivo | Para qué sirve |
|---|---|
| `01-listing-name.txt` | Nombre que aparece en el listing (75 chars max) |
| `02-description-short.txt` | Descripción corta (132 chars max) — bajo el título en la ficha |
| `03-description-long.md` | Descripción larga con secciones — cuerpo de la ficha |
| `04-privacy-policy.md` | Política de privacidad lista para hostear en una URL pública (obligatorio para extensiones con permisos) |
| `05-permissions-justification.md` | Textos preparados para cada permiso solicitado durante la revisión |
| `06-submission-checklist.md` | **Empieza por aquí.** Checklist paso a paso de la subida (30-45 min) |
| `promo/promo-440x280.png` | Small promotional tile (OBLIGATORIO) |
| `promo/promo-920x680.png` | Large promotional tile (opcional, recomendado) |
| `promo/promo-1400x560.png` | Marquee tile (opcional, para destacados) |
| `screenshots/` | Capturas 1280×800 (1-5 requeridas) — _pendiente: generar tras cargar la extensión_ |

## Y el ZIP de la extensión:

`../focus-guard-v1.0.0.zip` (56 KB) — listo para subir en el paso "Upload package" del dashboard.

## Próximos pasos

1. **Carga la extensión local** (Load unpacked) y verifica que todo funciona como esperas.
2. **Genera las screenshots** (te las preparo automáticamente cuando esté cargada).
3. **Hostea la política de privacidad** en una URL pública (GitHub Pages / Notion / Telegraph).
4. Sigue `06-submission-checklist.md` paso por paso.

## Costes

- **Chrome Web Store Developer**: 5 USD una vez (de por vida).
- **Hosting política privacidad**: 0 USD (GitHub Pages, Notion, Telegraph son gratis).
- **Revisión de Google**: 0 USD, 1-3 días hábiles.

Total: **5 USD una sola vez**.
